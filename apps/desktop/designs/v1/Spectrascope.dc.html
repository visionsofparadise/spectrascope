SPECTRASCOPE

Spectral Audio Inspector

v0.1.0

Source Strip

The atomic per-source visual unit — spectrogram plus waveform rendered in one source's layer color, no internal chrome. Used by Overlay, Timeline, Slider, Difference, and Sum.

View Tabs

The nine view tabs that drive the workspace switcher. Active state is a background-value shift; no underline. The right-side cluster is global: a Sync toggle, a Mono / Mid / Side channel-input selector, and undo / redo.

Layer Color + LayerColorPicker

Paler default layer palette (primary drives waveforms and chart traces; secondary is the accent stripe) plus the picker that edits both endpoints. Layer colors are user data, not design tokens — each source carries its own pair.

View Containers

Each view container composes its own chrome around one or more SourceStrips — or, for the chart views, its own plot. A small sample of each, against three demo sources.

OverlayView

N visible sources z-stacked in one viewport, blended via mix-blend-mode: lighten.

TimelineView

N visible sources stacked vertically — one row per source, each a SourceStrip in that source's layer color.

SliderView

Two visible sources clipped against each other by a draggable Curtain handle. Left shows A; right shows B.

DifferenceView

N inputs become N-1 derived A-B strips in a neutral layer color.

SumView

N inputs collapse into one derived sigma strip in a neutral layer color.

FrequencyDistributionView

One long-term-average-spectrum (LTAS) polyline per visible source on a single log-frequency / linear-dB chart.

LoudnessView

Per-source loudness metric traces (LUFS / RMS / true-peak), each in that source's primary.

CorrelationView

One inter-channel correlation trace per visible source on a shared time axis (+1 mono, 0 wide, -1 inverted).

VectorscopeView

A single shared (Side, Mid) density scope with every visible source's cloud overlaid, blended via lighten.

Transport

Media-only — a cursor / In / Out readout panel on the left, the centered media-control cluster with speed and timecode, and monitor volume on the right. Seeking is done on each view's time ruler.
